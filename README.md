Smart road damage reporting and management system.

- React
- Node.js
- Express
- MongoDB
- FastAPI
- YOLO
- Android

## Core Flow

Citizen
→ Image + Location
→ Node.js Backend
→ FastAPI + YOLO
→ Damage Detection
→ Severity
→ Priority
→ Admin Dashboard
→ Repair Assignment
→ Completion Verification
